# Career Journey Portfolio MVP

A scroll-based portfolio that tells your career journey through milestones, impact, projects, achievements, and contact links.

## Run locally

```bash
npm install
npm run dev
```

Open: http://localhost:3000

## Edit content

Update these files:

- `data/milestones.ts`
- `data/projects.ts`
- `data/achievements.ts`

## Deploy

Push to GitHub and deploy on Vercel.
